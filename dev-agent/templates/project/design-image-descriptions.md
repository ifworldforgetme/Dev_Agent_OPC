# Design Image HTML Descriptions: {{PROJECT}}

When an approved design asset is generated by imagegen, GPT Image, or another
AI image model, generate an HTML companion at the same time. The HTML file
describes the layout, visual hierarchy, content, components, states, colors,
spacing, typography, interactions, and implementation notes represented by the
image.

## Rules
- Save implementation-ready HTML companions under `design/approved/html/`.
- Store provider/source originals or rough HTML notes under `design/sources/html/`.
- Each AI-generated `DESIGN_ARTIFACTS.md` row must include the companion path in
  `Implementation notes`, for example `HTML: design/approved/html/dashboard.html`.
- The companion HTML should help an agent recreate the screen in Figma or code
  without relying only on visual interpretation of the bitmap.
- Browser screenshots, runtime pages, and HTML/CSS prototypes are not approved
  design assets. The HTML companion is a semantic description of the approved
  image, not the runtime implementation.
