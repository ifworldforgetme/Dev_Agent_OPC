---
description: Review security-sensitive behavior before implementation or launch
---

Invoke the `security-and-hardening` skill.

Use this for auth, permissions, payments, data deletion, secrets, uploads, external integrations, and production launch risk:

1. Identify assets, actors, trust boundaries, and abuse cases.
2. Check input validation, authorization, secret handling, data retention, and logging.
3. Review dependency and configuration risks.
4. Add tests or verification steps for high-risk paths.
5. Report blockers separately from recommendations.

Security blockers must be fixed or explicitly accepted by the user before launch.
