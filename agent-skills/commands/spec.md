---
description: Write a structured specification before implementation
---

Invoke the `spec-driven-development` skill.

Read the approved idea artifacts and create a buildable spec:

1. Define the objective, target users, and user-visible outcomes.
2. Write core features, acceptance criteria, and explicit non-goals.
3. Document stack constraints, commands, project structure, code style, tests, and boundaries.
4. For customer-facing UI, point to the design phase before implementation planning.
5. Save the spec under `work/<project-name>/specs/SPEC.md`.

Confirm with the user before proceeding unless the user has explicitly delegated defaults.
