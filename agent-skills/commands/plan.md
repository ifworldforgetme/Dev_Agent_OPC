---
description: Break approved work into small verifiable tasks
---

Invoke the `planning-and-task-breakdown` skill.

Read the approved spec and design artifacts, then plan without editing production code:

1. Identify source boundaries and dependencies.
2. Slice work vertically into small deliverable tasks.
3. Give each task acceptance criteria and verification commands.
4. Add checkpoints for human review gates.
5. Save the plan under `work/<project-name>/tasks/PLAN.md`.
6. Update `work/<project-name>/tasks/PDCA.md` Current Cycle and Plan with scope, checkpoint, objective, source artifacts, acceptance criteria, and quality gates.

Use project-local paths such as `work/<project-name>/apps/mobile/...`.
