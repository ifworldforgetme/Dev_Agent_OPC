description: Recover the current Dev Agent project phase and next executable brief
---

Use this as `/dev-next <project-name>`.

This is the autocomplete-friendly shortcut for `/dev agent next <project-name>`.

Run `bin/dev-flow status <project-name>` and `bin/dev-flow next <project-name>`. If project-local `bin/dev-flow` is unavailable, use the installed `dev-agent-runtime/bin/dev-flow`.

Load only the files named in the `next` brief, then continue with the listed command file, primary skill files, required outputs, blocker checks, gate, and follow-up `phase` command.
