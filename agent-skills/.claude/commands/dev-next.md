description: Recover the current Dev Agent phase and next executable brief
---

Use this as `/dev-next <project-name>`.

Shortcut for `/dev agent next <project-name>`.

Run `bin/dev-flow status <project-name>` and `bin/dev-flow next <project-name>`. Load only the files named in the brief, then continue with the listed command file, skills, outputs, gate, and follow-up `phase` command.

Prefer project-local `bin/dev-flow`; otherwise use the installed `dev-agent-runtime/bin/dev-flow`.
